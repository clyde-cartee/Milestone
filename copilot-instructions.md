# simple web game starting screen

# user story
This will be the starting screen for a simple web game. The user should be able to see the game title, a brief description, and a "Start Game" button. When the user clicks the "Start Game" button, they should be taken to the main game screen.

This game will be called time dungeon. The goal of the game is to gamify studying. The more time you are studying and recording it the more points you earn to customize your character and unlock new levels. The game will have a simple and intuitive interface that encourages users to track their study time and stay motivated. This is just to develop the starting screen for the game. The main game screen will be developed in a separate development phase. 

# requirements 
- The starting screen should have a visually appealing design that reflects the theme of the game.
- The game title should be prominently displayed at the top of the screen.
- A brief description of the game should be displayed below the title, explaining the objective and how to play.
- A "Start Game" button should be prominently displayed on the screen, and it should be easy to find and click.
